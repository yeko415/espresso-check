# Motion Engine Starter v4

A reusable, original implementation inspired by the interaction architecture observed in the supplied Impossible Foods reference:

- pill-shaped sticky top navigation
- oversized condensed typography
- floating masked hero imagery with independent parallax speeds
- product section with large category tabs and centered horizontal product rail
- wheel / drag / arrows to move the product rail
- pinned tall product scene to make scroll feel like a moving canvas
- large recipe section with asymmetric image masks
- dark mission feature panel with tab-style navigation
- FAQ accordion
- responsive/mobile fallbacks
- reduced-motion accessibility support

All site copy and image selection are demo content rather than a reproduction of the source site's copy/assets.

GitHub Pages: put `index.html`, `styles.css`, and `app.js` in the repository root.
