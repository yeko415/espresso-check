# NERO / 24 — Reusable Website Starter

Bu paket tek bir işletmeye bağlı olmayan, başka müşteri sitelerine hızlıca uyarlanmak için hazırlanmış frontend starter'dır.

## Yapı
- `index.html` — semantik sayfa iskeleti ve component markup
- `assets/styles.css` — design tokens, responsive layout ve component stilleri
- `assets/app.js` — mobil menü, filtreler, reveal animasyonları ve demo form davranışı

## Tasarım altyapısı
CSS variables üzerinden renk, spacing, radius, font ve max-width merkezden yönetilir. İçerik değiştirirken component yapısını koruyup sadece token'ları ve veri/medya katmanını değiştirebilirsin.

## Not
Görseller demo amacıyla Unsplash URL'lerinden geliyor. Gerçek projede `/assets/images` altına yerel asset'ler koyup `<img src>` yollarını değiştirmen daha sağlam olur.
